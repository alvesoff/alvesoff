### About

- **~20 internal systems** used every day by schools, a library and the back office, running on Oracle Cloud Kubernetes (OKE).
- Complex integrations with **Oracle NetSuite**, **Microsoft 365** and **D4Sign**. For the public artist calls of the [Biblioteca Sinhá Junqueira](https://bsj.org.br), each application flows to selection, purchase order and an e-signed contract with no manual steps: **280+ applications and 80+ contracts** in the last two calls.
- Own **MCP servers** that let Claude Code operate those systems, and several AI agents working in parallel under orchestration.

### Building with AI

| Project | What it does | AI in it |
|---|---|---|
| **Educandário Integrado** *(internal)* | Portal with the foundation's internal systems behind a single Microsoft sign-on: attendance for 3 schools, library artist contracts, purchase quote comparison and Microsoft 365 account admin. | MCP server so Claude Code reads and operates the systems, with a preview and explicit confirmation on every change |
| [**Proline Voice**](https://prolinevoice.com) | AI voice agent that answers real phone calls in English for Brazilian service providers in the US: negotiates within the owner's price rules, books the job and sends a summary in Portuguese to Telegram. | Voice agent on Vapi (Deepgram + Cartesia), Claude (Anthropic API) for call summaries and translations |
| [**OpenSeed**](https://openseed.com.br) | My startup from Ribeirão Preto, building software products like Proline Voice, with Silicon Valley as the goal. | Team task board with its own MCP server, so Claude Code assigns, tracks and reviews the work |
